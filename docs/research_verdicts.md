# Verdict vocabulary

| Verdict | Meaning |
|---|---|
| SUPPORTED | The pre-specified criteria were met on the evidence examined |
| PARTIALLY SUPPORTED | Some pre-specified criteria were met, others not |
| NOT SUPPORTED | The pre-specified criteria were not met |
| INCONCLUSIVE | The evidence cannot distinguish the hypothesis from its alternatives |

Distinctions that must be kept:

- **NOT SUPPORTED** is not the same as **NOT TESTED**. A test that could not be run for lack of defensible inputs (for example, financing costs) is *not formally tested*, not "no edge".
- **Mechanical correctness** (the code does what it is specified to do) is a different finding from **economic edge**.
- **Insufficient mechanism engagement** (a guard never activated) is not evidence that the idea is false.
- A result on a development partition is not confirmation. Confirmation needs untouched evidence.

This repository ships no empirical verdicts about any market. It provides the tools and the discipline for producing them.
